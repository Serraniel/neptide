# Contributing

- Open an issue before large changes. Run the integration tests in `test/integration/` for changes to `pkg/rollout`.
- PR titles follow [Conventional Commits](https://www.conventionalcommits.org/) (`feat(stacks): …`, `fix: …`), because they become the changelog.
- Run `go test ./...` and `golangci-lint run` before pushing.
- Contributions are licensed under AGPL-3.0-or-later.
